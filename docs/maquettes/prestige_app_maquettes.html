Prestige Pharmacien (prestige_app) — propositions de refonte

Même charte que prestige_vente_app : bleu Prestige #003366, ambre #F59E0B pour l'action principale, fond gris clair, cartes blanches arrondies. Trois présentations au choix : ATableau de bord (chiffres du jour en tête, recommandée pour le pharmacien), BCompact (listes denses, tableaux, pour l'utilisateur expérimenté ou la tablette), CGuidé (questions simples, gros boutons, pour un adjoint ou un gérant occasionnel). Les écrans d'origine restent disponibles par un interrupteur « Nouvelle interface ». Les chiffres sont fictifs.

1. Connexion

Le serveur est vérifié avant la saisie ; le mot de passe n'est plus enregistré sur le téléphone ; les erreurs disent clairement si c'est le réseau ou les identifiants.

2. Accueil / tableau de bord

Aujourd'hui : 27 menus en pages de 6 tuiles à faire défiler. Proposé : les chiffres du jour d'abord, les alertes ensuite, puis tous les menus rangés par familles sur une seule page.

3. Une liste type : Suivi crédit

Filtres en puces au-dessus, total toujours visible, et surtout : une panne réseau s'affiche comme une panne (avec « Réessayer »), jamais comme « Aucun résultat ».

4. Un écran d'analyse : chiffre d'affaires

Période en puces (Aujourd'hui, 7 j, Mois, Année, Personnalisée), un chiffre principal, une seule échelle par graphique, tableau détaillé à côté.

5. Nouveau module « Présences » (téléphone)

Données lues sur les routes RH existantes du serveur (/rh/presence, /rh/tableau, /rh/employes), réservées au droit P_SM_RH. Les pointages sont faits sur les téléphones des employés (prestige_vente_app) ou à la pointeuse.

6. Présences sur tablette et QR code du jour

Sur tablette, menu latéral et deux colonnes. L'onglet « Pointage » affiche le QR code qui change chaque minute (GET /rh/mobile/code) : une tablette posée au comptoir sert d'écran de pointage pour les téléphones des employés ; la liste des téléphones vient de /rh/mobile/terminaux.
